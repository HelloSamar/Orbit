# Setup

## Requirements

- Node.js 18+
- npm
- Git

## Install

```bash
git clone https://github.com/HelloSamar/Orbit.git
cd Orbit
npm install
```

## Run locally

```bash
npm start
```

## Build

```bash
npm run build
```

## Local pairing

Orbit is designed to work across devices on the same local network. Start the app on each device and pair them using the local pairing flow.
